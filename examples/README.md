# 🚀 Quick Examples

This folder contains **minimal, copy-paste ready scripts** to get started with matplotlib quickly.

## 📝 Available Examples

### 1. `quick_start.py`
**10-line minimal example** - Your first matplotlib plot
```bash
python examples/quick_start.py
```

### 2. `publication_figure.py`
**Academic paper-ready** - Publication-quality figure in one script
```bash
python examples/publication_figure.py
```

### 3. `batch_process.py`
**Process multiple datasets** - Loop through CSV files and create plots
```bash
python examples/batch_process.py
```

### 4. `custom_theme_example.py`
**Apply custom themes** - Use project themes with one function call
```bash
python examples/custom_theme_example.py
```

### 5. `animation_example.py`
**Simple animation** - Create an animated plot in <20 lines
```bash
python examples/animation_example.py
```

---

## 💡 Philosophy

These examples are designed to be:
- ✅ **Minimal** - Under 30 lines of code
- ✅ **Self-contained** - No external dependencies beyond project utils
- ✅ **Copy-paste ready** - Grab and modify for your needs
- ✅ **Documented** - Clear comments explaining each step

## 🎯 When to Use

- **Learning** - Start here before diving into notebooks
- **Quick prototyping** - Need a plot fast
- **Code snippets** - Copy patterns into your projects
- **Templates** - Starting point for custom visualizations
